# Tarde de Bingo · Made in Talca

Cantador de bingo para la primera Tarde de Bingo de Made in Talca. Es una sola página (`index.html`) pensada para proyectarse en una TV 16:9: muestra el número cantado en grande, el tablero B-I-N-G-O con los números que ya salieron y una marquesina con los anteriores.

## Uso

Abre `index.html` en el navegador y ponlo en pantalla completa. No necesita instalación ni conexión, salvo para cargar las tipografías.

| Tecla | Acción |
|---|---|
| `Espacio` / `Enter` / `→` | Sacar el siguiente número |
| `←` / `Backspace` | Deshacer el último número |
| `N` | Nueva partida |
| `V` | Activar o desactivar la voz |
| `M` | Muerte súbita |
| `O` | Ocultar o mostrar los botones |

También funciona con presentadores inalámbricos (`PageDown` / `PageUp`). Se puede cantar un número a mano haciendo clic en él en el tablero.

### Muerte súbita

Sirve para desempatar entre cartones. Cada cartón saca una bolita (del 1 al 75, sin repetir) y gana la más alta.

1. `←` `→` para elegir cuántos cartones hay en disputa.
2. `Espacio` para empezar y `Espacio` para sacar cada bolita.
3. El ganador se marca solo. `Espacio` vuelve al bingo, `R` juega otra ronda y `Esc` sale.
